# 11 UI 优化说明（第九阶段：韩风可爱）

整体从“高级低饱和”调整为**韩风可爱**：奶油底、蜜桃粉、大圆角、贴纸感卡片、柔和阴影、emoji 点缀。

## 设计令牌

| 项 | 旧值 | 新值 |
| --- | --- | --- |
| 背景 | #FAF7F2 米白 | #FFF7F0 奶油 |
| 主色 | #D98E8E 低饱和粉 | #FF96A1 蜜桃粉（主按钮用渐变 #FFB3BB→#FF96A1） |
| 强调 | #E0A06E | #FFC28E 奶油橙 |
| 蓝色 | #7FA3B8 | #9BC7DE 薄荷蓝 |
| 红色 | #C96F6F | #F56A6A 温柔红 |
| 成功/危险 | #7FA98C / #C0564F | #A8D8B9 抹茶绿 / #F2556D 草莓红 |
| 圆角 | 8/14/20rpx | 16/24/36rpx |
| 阴影 | 无 | 卡片/柔和两层粉色阴影 |

新增令牌：`purple`（香芋紫）、`mint`（薄荷绿）、`primaryDeep`（深蜜桃）、`shadow-card`、`shadow-soft`。
同步位置：`packages/design-tokens/src/index.ts` ↔ `apps/miniprogram/miniprogram/style/theme.wxss`。

## 全局样式（app.wxss）

- 按钮全部胶囊形（999rpx），主按钮粉色渐变 + 轻阴影 + 按下缩放反馈；
- 卡片贴纸化：白底、大圆角、粉色柔和阴影；
- 输入框奶油底 + 浅粉描边；
- chip 标签胶囊化；空状态居中并带 emoji；
- 页面标题加粗 + 字距。

## 页面亮点

- **首页**：问候卡（🏡 우리들의 집 + 空间名 + 角色徽章 + 邀请码胶囊）、今天摘要卡、6 宫格功能入口（📅🍚🍴❤️✈️🛠️ 各配马卡龙底色）、成员卡带 emoji 头像、虚线分隔。
- **日历**：今天粉色底、选中日粉色渐变胶囊、生理期/休息柔和色块、图例胶囊化、日程条浅粉描边、按钮带 emoji。
- **业务页**：餐厅/纪念日/旅行卡片统一大圆角 + 阴影，列表用虚线分隔，动作按钮胶囊化。

## 说明

- 未改任何业务逻辑与数据模型，仅样式层（WXML/WXSS/令牌）。
- 微信小程序不支持外部字体，使用系统圆润字体栈（PingFang SC / 微软雅黑）。

## 增补：首页改为“日历优先”

按需求调整首页布局（2026-08-14）：

1. **一打开就是日历**：首页顶部直接内嵌可复用的月历组件（`components/month-calendar`，支持翻月/今天/点选日期/勾选待办/点击日程跳转业务页），再点击“打开完整日历”进入功能完整版日历页。
2. **功能项排成一列**：日历下方是竖向功能列表（完整日历 / 今日菜单 / 漂亮饭 / 纪念日 / 旅游计划 / 管理），每行 emoji + 标题 + 说明 + 箭头。
3. **邀请码缩在右上角**：仅主账号且未绑定时，右上角小胶囊显示邀请码，点击复制；已绑定则显示 💗。
4. **昵称自定义 + 爱心连接**：
   - 双人各自可以改自己的昵称（点击左侧自己的头像/名字，最多 16 字）；
   - 顶部显示“我 ❤️ 对方”爱心连接，昵称双方互见；
   - 后端：`space-info` 云函数新增 `set-nickname`，只能修改自己的昵称（`space_members.nickname`）。

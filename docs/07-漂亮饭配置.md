# 07 漂亮饭：外部服务配置（搜索 / OCR / 存储）

漂亮饭涉及三个外部能力，全部按“免费优先、按需调用、不保存敏感数据”设计。

## 1. 餐厅搜索（腾讯位置服务）

已核对官方配额（2025-11-13 更新）：**个人开发者每日 200 次 / QPS 5，个人学习非商用免费**。
本项目只有两个人，绰绰有余；搜索结果会由用户确认后再保存，不做批量抓取。

配置步骤（一次性，约 10 分钟）：

1. 打开 [lbs.qq.com](https://lbs.qq.com)，用微信扫码登录，注册为**个人开发者**；
2. 控制台 → 应用管理 → 创建应用（类型选“微信小程序”，填 AppID `wxeb504455382aa16b`）；
3. 在应用里新建 Key，勾选 **WebServiceAPI**；
4. 把 Key 填入云函数 `restaurant-search` 的环境变量 `LBS_KEY`：
   - 云开发控制台 → 云函数 → restaurant-search → 配置 → 环境变量 → 新增 `LBS_KEY`，保存并重新部署；
5. 回到小程序“漂亮饭 → 搜索导入”即可使用。

未配置时不会报错崩溃，而是提示“请在 LBS_KEY 填入 Key”，手动录入照常可用。

## 2. 菜单 OCR（微信云调用）

使用微信云调用 `ocr.printedText`（免费，500 次/天）。

- OCR 只把识别结果作为**草稿**填进表单，由用户核对确认后才保存，不会直接修改正式数据；
- 需要小程序为**已认证**状态；未认证时调用会提示错误，可改用手动录入；
- 仅把“用户主动选择的那张图片”发给 OCR，不发送任何其他私人数据。

## 3. 图片存储与隐私

餐厅封面 / 餐厅照片 / 菜单图片上传到 CloudBase 云存储，客户端先压缩
（长边约 1600px、质量 75 的 JPEG，目标几百 KB）。

建议把云存储权限设为 **“仅创建者可读写”**：

云开发控制台 → 存储 → 权限设置 → 选择“仅创建者可读写”。

这样两位成员互相看不到对方文件的直链；页面展示时由云函数换取临时地址，
避免把私人照片暴露成永久公开链接（临时地址会过期）。

## 4. 定位与导航

- 只在用户点击“怎么去”时获取当前位置（`wx.getLocation`）；
- 不保存位置、不记录轨迹；
- 调起微信内置腾讯地图（`wx.openLocation`）显示步行/公交/驾车方案，不自研导航。

## 常见错误

| 现象 | 原因与解决 |
| --- | --- |
| 搜索提示 LBS_NOT_CONFIGURED | 未配置 `LBS_KEY`，按上文第 1 节操作 |
| 搜索提示“配额不足” | 个人开发者每日 200 次用尽，次日恢复；本项目用量极低 |
| OCR 提示失败 | 小程序未认证或文件超 2M；改用手动录入，或压缩后重试 |
| 图片显示不出来 | 存储权限未设为“仅创建者可读写”时，临时地址可能受限；检查第 3 节 |

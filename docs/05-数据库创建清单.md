# 05 数据库创建清单（照着做即可）

打开方式：微信开发者工具 → 工具栏「云开发」→ 左侧「数据库」。

## 一、创建 5 个集合

在「集合管理 / 集合列表」页面点 **＋（新建集合）**，依次创建，名称**一字不差**：

```text
users
user_identities
spaces
space_members
audit_logs
```

创建时不需要导入任何数据，第一阶段集合都是空的，数据由云函数写入。

## 二、设置权限（每个集合各做一次）

点开集合名 → 找到「数据权限 / 权限设置」→ 选择：

**「所有用户不可读写」**

如果想用自定义规则，也可以选「自定义安全规则」并粘贴（5 个集合用同一段）：

```json
{
  "read": false,
  "write": false
}
```

含义：手机上的小程序端不能直接读/写数据库，只有云函数（服务端）可以。这是本项目安全的第一道闸。

## 三、创建 3 组唯一索引

每个集合 →「索引管理」→「新建索引」：

| 集合 | 字段 1（升序） | 字段 2（升序） | 唯一 |
| --- | --- | --- | --- |
| user_identities | provider | providerUserId | ✅ 勾选 |
| spaces | ownerUserId | （不加） | ✅ 勾选 |
| space_members | spaceId | userId | ✅ 勾选 |

创建后「索引管理」里应有：

```text
user_identities：_id(默认) + provider,providerUserId（唯一）
spaces：_id(默认) + ownerUserId（唯一）
space_members：_id(默认) + spaceId,userId（唯一）
```

作用：防止同一微信重复建账号、一人拥有多个空间、一人重复加入同一空间（数据库层面的最后防线）。

## 四、完成后验证

- 数据库集合列表有 5 个集合，名称完全一致；
- 点开每个集合 → 数据列表为空；
- 点开每个集合 → 索引管理里有上表的索引；
- 之后部署云函数、在小程序里操作，数据会出现在这些集合里。

## 常见错误

| 现象 | 原因与解决 |
| --- | --- |
| 提示集合已存在 | 名称重复，第一阶段集合应为空，可删除重建或直接继续使用 |
| 找不到「数据权限」 | 不同版本入口叫法不同，找「权限设置 / 安全规则 / 数据权限」，或点集合名进入详情页 |
| 唯一索引创建失败 | 说明集合里已有重复数据（第一阶段应为空）；如已有数据，先清理再建 |
| 忘记勾选「唯一」 | 索引不唯一就失去了防重复作用，删除后重建并勾选 |

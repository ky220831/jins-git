# 13 备份与数据维护（1.1.0+）

## 一、数据备份

### 数据库备份（本地脚本）

把云数据库全部集合导出为本地 JSON：

```powershell
# 1. 获取临时密钥（替换为你的环境 ID）
$raw = tcb secrets get -e cloud1-d7g10lhi6a6ccb999 --json | ConvertFrom-Json
$env:TENCENTCLOUD_SECRETID = $raw.data.secretId
$env:TENCENTCLOUD_SECRETKEY = $raw.data.secretKey
$env:TENCENTCLOUD_SESSIONTOKEN = $raw.data.token
$env:TENCENTCLOUD_TOKEN = $raw.data.token
$env:CLOUDBASE_ENV_ID = $raw.data.envId

# 2. 导出（写入 outputs/backup/日期/）
npm run backup
```

### 照片/文件备份

CloudBase 控制台 → 存储 → 文件，可手动批量下载；数据库侧建议同时在控制台开启“自动备份/回档”（云开发控制台 → 数据库 → 备份），它们是平台级能力，无需额外代码。

### 建议节奏

- 每周一次 `npm run backup`（或用 Windows 计划任务定时执行）。
- 每次发版前手动备份一次。

## 二、年度节假日更新（2027 及以后）

见 [docs/06-节假日年度更新.md](06-节假日年度更新.md)（含模板生成、校验、导入与
政策中途调整的完整步骤）。核心命令：

```powershell
node scripts/import-holidays.cjs --template 2027        # 生成年度模板
node scripts/import-holidays.cjs holidays-2027.json --dry-run   # 只校验
node scripts/import-holidays.cjs holidays-2027.json     # 正式导入
```

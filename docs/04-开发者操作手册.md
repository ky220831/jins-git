# 04 开发者操作手册（零基础版）

本文按顺序做，每步告诉你要看什么。看不懂的术语第一次出现时会解释。

## 第 1 步：安装微信开发者工具（还没有装）

开发者工具 = 微信官方提供的“编程 + 预览 + 部署”一体软件。

1. 浏览器打开官方下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选「稳定版 Stable Build」里的 **Windows 64 位**，下载并双击安装；
3. 打开后用**你自己的微信扫码登录**。

应看到：开发者工具主界面。

## 第 2 步：导入项目

1. 点「导入项目」；
2. 目录选择本项目里的 `apps/miniprogram` 文件夹；
3. AppID 选择你注册的小程序（如列表没有，选“测试号”先体验也可以，但云开发需要真实 AppID）；
4. 点「确定」。

应看到：左侧模拟器出现“我们的生活”登录页。

## 第 3 步：开通云开发

1. 点工具栏「云开发」按钮；
2. 点「开通」，按提示创建**免费云环境**；
3. 记下环境 ID（形如 `cloud1-xxxx`）。

只有一个环境时不用改代码；打开 `apps/miniprogram/miniprogram/config/env.ts`，保持 `ENV_ID = ''`。

## 第 4 步：创建 5 个集合

在「云开发」控制台 →「数据库」→ 点「新建集合」，依次创建：

```text
users
user_identities
spaces
space_members
audit_logs
```

## 第 5 步：设置安全规则（每个集合都要做）

对每个集合：点集合名 →「权限设置」→「自定义安全规则」→ 粘贴下面的 JSON → 保存：

```json
{
  "read": false,
  "write": false
}
```

含义：所有客户端都不能直接读写数据库，数据只能通过云函数访问。参考文件：
`docs/security-rules/collection-rules.json`。

## 第 6 步：设置索引（防重复）

每个集合 →「索引管理」→「新建索引」：

| 集合 | 字段（升序） | 勾选“唯一” |
| --- | --- | --- |
| user_identities | provider, providerUserId | ✅ |
| spaces | ownerUserId | ✅ |
| space_members | spaceId, userId | ✅ |

## 第 7 步：构建并部署云函数

云函数 = 跑在云端的一段代码，小程序通过名字调用它。

1. 打开 **PowerShell**（开始菜单搜索 PowerShell）；
2. 进入项目根目录：
   ```powershell
   cd C:\Users\22970\Documents\Codex\2026-08-13\v1-0-codex-prd-ui-ux
   ```
3. 安装依赖并构建（每个命令单独粘贴、回车，等它执行完）：
   ```powershell
   npm install
   npm run sync
   npm run build
   ```
4. 回到微信开发者工具，左侧文件树展开 `cloudfunctions`；
5. 对以下 4 个文件夹**分别右键** →「上传并部署：云端安装依赖」：
   ```text
   auth-login
   space-create
   space-join
   space-info
   ```

应看到：每个函数上传成功；云开发控制台「云函数」列表出现这 4 个名字。

> 提示：如果云函数创建时默认运行时是 Nodejs16.13，建议在云开发控制台 → 云函数 → 对应函数
> →「函数配置」中把运行时改为 **Nodejs18.15**（或更高）后再上传，与本项目打包目标一致。

## 第 8 步：手机验证（两部手机）

1. 手机 A（主账号）：
   - 开发者工具点「预览」，手机微信扫码；
   - 进入小程序 →「微信一键登录」→「创建空间」→ 起名字 → 看到 8 位邀请码，点一下复制。
2. 手机 B（副账号）：
   - 先在微信公众平台 mp.weixin.qq.com →「成员管理」→ 添加手机 B 为**体验成员**；
   - 手机 B 微信扫同一个预览码（或用体验版）；
   - 登录 →「加入空间」→ 粘贴邀请码 →「绑定成功」。
3. 验证：
   - 手机 A 首页显示「双人已绑定 ✅」；
   - 手机 B 首页显示「副账号 MEMBER」；
   - 手机上没有任何地方能看到对方的 OPENID 或完整用户 ID（只显示后 8 位）。

## 第 9 步：跑安全测试（可随时重复）

PowerShell 中执行：

```powershell
npm test
```

全部通过后，第一阶段开发侧完成。后续阶段在确认后再开始。

## 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 提示“当前基础库不支持云能力” | 开发者工具右下角基础库版本过低，升级到最新稳定版 |
| 登录一直失败 | 云函数 `auth-login` 未部署，或集合未创建，检查云函数日志 |
| 邀请码无效 | 确认复制完整 8 位、未过期、未被使用；被绑定后邀请码自动失效 |
| 我属于另一个空间 | 一个微信只能属于一个空间，退出后才能创建/加入（退出功能后续阶段提供） |
| 云函数上传后调用报 INTERNAL | 云开发控制台 → 云函数 → 对应函数 → 日志，查看具体报错 |

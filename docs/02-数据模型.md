# 02 数据模型（第一阶段）

## 集合与字段

### users

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | 业务用户 ID（`u_...`） |
| `status` | string | `active` / `disabled` |
| `createdAt` / `updatedAt` | Date | 创建/更新时间 |

### user_identities

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `ui_...` |
| `userId` | string | 关联 users |
| `provider` | string | 固定 `wechat_miniprogram` |
| `providerUserId` | string | 微信 OPENID |
| `createdAt` | Date | 创建时间 |

### spaces

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `sp_...` |
| `name` | string | 空间名称（1~20 字符） |
| `ownerUserId` | string | 主账号用户 ID |
| `status` | string | `active` / `disabled` |
| `memberCount` | number | 当前成员数（1 或 2） |
| `inviteCode` | string \| null | 一次性邀请码，绑定后置空 |
| `inviteCodeExpiresAt` | Date \| null | 邀请码过期时间（默认 7 天） |
| `inviteCodeUsedAt` | Date \| null | 绑定成功时间 |
| `version` | number | 版本号（供后续乐观锁） |
| `createdAt` / `updatedAt` | Date | 时间戳 |

### space_members

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `sm_...` |
| `spaceId` | string | 关联 spaces |
| `userId` | string | 关联 users |
| `role` | string | `owner` / `member` |
| `status` | string | `active` / `left` |
| `joinedAt` | Date | 加入时间 |
| `createdAt` / `updatedAt` | Date | 时间戳 |

### audit_logs

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `al_...` |
| `spaceId` | string \| null | 空间 ID |
| `actorUserId` | string | 操作人 |
| `action` | string | 例如 `space.create` / `space.join` |
| `targetType` / `targetId` | string \| null | 操作对象 |
| `result` | string | `success` 等 |
| `detail` | string | 可选补充（不记录敏感内容） |
| `createdAt` | Date | 时间戳 |

### todos（第二阶段）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `td_...` |
| `spaceId` | string | 关联 spaces |
| `title` | string | 标题（1~100 字符） |
| `date` | string | 日期键 `YYYY-MM-DD`（Asia/Shanghai） |
| `time` | string \| null | `HH:mm`，可选 |
| `note` | string \| null | 备注 |
| `priority` | string | `low` / `normal` / `high` |
| `status` | string | `pending` / `completed` / `archived` |
| `businessType` / `businessId` | string \| null | 业务关联（后续阶段） |
| `createdBy` | string | 创建人 |
| `createdAt` / `updatedAt` | Date | 时间戳 |
| `version` | number | 乐观锁版本 |

### calendar_events（第二阶段）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_id` / `id` | string | `ce_...` |
| `spaceId` | string | 关联 spaces |
| `sourceType` | string | `todo` / `meal` / `restaurant` / `anniversary` / `trip` / `period` / `custom` |
| `sourceId` | string | 业务记录 ID（业务数据是唯一真实来源） |
| `title` | string | 展示标题 |
| `startTime` | Date | 开始时间（Asia/Shanghai） |
| `endTime` | Date \| null | 结束时间（可选） |
| `colorToken` | string \| null | 统一颜色 Token |
| `createdBy` | string | 创建人 |
| `createdAt` / `updatedAt` | Date | 时间戳 |
| `version` | number | 乐观锁版本 |

## 索引（云开发控制台 → 数据库 → 索引管理 → 新建）

| 集合 | 字段 | 唯一 |
| --- | --- | --- |
| user_identities | provider + providerUserId | ✅ 唯一 |
| spaces | ownerUserId | ✅ 唯一 |
| space_members | spaceId + userId | ✅ 唯一 |
| todos | spaceId + date | ❌（普通索引，按月查询） |
| calendar_events | spaceId + startTime | ❌（普通索引，按月查询） |

## 后续阶段集合路线图

| 集合 | 阶段 | 生命周期 |
| --- | --- | --- |
| Todo | 2 | 永久（完成归档） |
| CalendarEvent | 2 | 随业务联动 |
| PeriodRecord | 3 | 最多 2 actual + 1 predicted |
| CalendarNote / CalendarTag | 3 | 永久 |
| HolidayCalendar | 3 | 按年度版本管理 |
| MealTemplate | 4 | 永久素材库 |
| MealPlan | 4 | 临时 14 天 |
| Restaurant | 5 | 永久 |
| RestaurantVisit | 5 | 临时 14 天 |
| Anniversary | 6 | 永久 |
| Trip / TripItem | 6 | Trip 永久 / 行程项可临时 |
| TrashRecord | 4 起 | 72 小时 |

所有业务表统一带 `spaceId`、`createdBy`、`createdAt`、`updatedAt`、`version`；临时数据额外带
`expireAt`、`deletedAt`、`purgeAt`，为 14 天清理与 72 小时回收站铺路。

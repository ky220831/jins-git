# 09 管理模块（第七阶段）

## 1. 主管理（仅主账号）

首页 → 管理 进入；副账号看到的是“副管理”，主账号看到的是“主管理”。

- **数据概览**：各业务（To Do / 菜单素材 / 今日菜单 / 餐厅 / 餐厅行程 / 纪念日 / 旅行资料 / 旅游行程 / 回收站）计数。
- **数据导出**：一键导出全部业务数据为 JSON，上传到云存储并返回**临时链接**（1 小时有效），不永久公开；仅主账号可导出。
- **回收站**：
  - 按类型筛选、单条恢复/永久删除；
  - 勾选多条 → 批量恢复 / 批量永久删除；
  - 清空回收站（全局清理，二次确认）。
  - 72 小时到期后由定时任务自动永久删除。
- **家庭管理**：成员列表、邀请码展示/复制、重新生成邀请码（旧码立即失效，新码 7 天有效）。
- **业务管理入口**：今日菜单 / 漂亮饭 / 纪念日 / 旅游计划。

## 2. 副管理（仅副账号）

只包含两项下架操作（双人权限表里副账号本就有下架权限）：

- 今日菜单下架（当天已上架的菜单）；
- 漂亮饭下架（已上架的餐厅）。

副账号看不到主管理的任何内容；后端对概览/导出/回收站/批量操作/重发邀请码统一返回 `FORBIDDEN`。

## 3. 后端接口

- 新云函数 `manage`：`overview`（主管理概览）、`export`（导出 JSON → 临时链接）。
- `trash` 云函数新增：`restore-many`、`purge-many`、`purge-all`。
- `space-info` 云函数新增：`regen-invite`（重发邀请码）。

## 4. 验证

- 单元测试：`tests/manage.test.ts`（权限、批量操作、清空、导出载荷、重发邀请码、跨空间）。
- 云端 E2E（真实云数据库）：`npx tsx scripts/cloud-e2e-manage.ts`，13 项全部通过。

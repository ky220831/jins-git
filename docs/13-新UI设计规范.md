# 「我们的生活」新 UI 设计规范 V2

> 轻奢高级简约 · 信息效率优先 · 随时节动态换肤
>
> 适用版本：v1.2+（设计先行，工程按此规范落地）

---

## 1. 设计基调

1. **轻奢高级简约**：低饱和色系、大面积留白、精致细微渐变、柔和阴影、线条克制、层次通透。
2. **信息效率优先**：日历是核心页面，可读性永远高于装饰；美观服从信息识别效率。
3. **克制**：不使用卡通元素、高饱和荧光色、厚重贴图、复杂异形图形。
4. **贯通**：所有页面组件、配色、圆角、字体规范统一，视觉体系一体化。

## 3. 字体规范（无衬线）

字体栈：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Helvetica Neue', 'Microsoft YaHei', sans-serif`。

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 大标题 | 40rpx | 600 | 页面主标题 |
| 区块标题 | 32rpx | 600 | 卡片标题、弹窗标题 |
| 正文 | 28rpx | 400 | 正文、表单标签 |
| 辅助 | 24rpx | 400 | 说明文字、农历、时间 |
| 日历日期 | 30rpx | 500 | 日历格内日期数字 |
| 日历农历 | 20rpx | 400 | 日历格内农历 |
| 标签 | 20rpx | 500 | 分类标签、徽章 |

字重规范：标题 ≤600，正文 400，标签 500；禁止 700+（避免廉价感）。

## 6. 日历页硬性规范

1. **日期数字始终清晰**：日程标记（圆点/标签）一律放日期格边缘，严禁压字；最多 4 个圆点 + 数字角标。
2. **今日 / 选中 / 过往 / 未来差异化柔和**：不使用浓烈色块；今日=主色描边，选中=主色浅底+描边，过往=文字降明度，未来=常规。
3. **日程列表同色系不同明度**：选中日期下方列表按分类使用同色系标签，主次分明，维持高级调性。
4. **年月切换简洁精致**：胶囊切换器融入顶部，不占多余高度。
5. 农历与节假日信息保留在日期格内，字号 ≤20rpx，克制显示。
6. 信息密度：格子内最多「日期 + 农历 + 标记」，详情点击后进入日程面板。

## 7. 动态换肤工程落地

1. **结构不变**：所有动态主题只替换 CSS 变量与背景纹理，页面布局与组件结构保持不动。
2. **纹理**：只用 CSS 线性渐变模拟（双层微渐变），禁止图片贴图与复杂滤镜。
3. **切换动画**：120–200ms 透明度过渡；禁止复杂动效；页面切换不叠加多个动画。
4. **优先级**：节日点缀 > 节气主题 > 昼夜模式 > 用户手动锁定；优先级可配置。
5. **降级**：夜间模式仅需一组深色变量，若设备性能受限可关闭纹理只留纯色。
6. **性能约束**：不新增图片资源、不引入重型动画库、不高频更新主题（按日判定缓存）。

---

## 8. 无障碍与触控

- 触控目标高度 ≥ 88rpx（44px）。
- 可点击元素有明确视觉反馈（按压态）。
- 文字对比度满足 2.4 节约束。
- 换肤不影响可读性：动态层只动背景与点缀，正文/标签/主色恒定。

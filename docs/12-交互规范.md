# 12 交互规范：新增/编辑表单统一使用底部弹窗（2026-08-14 定稿）

以【今日菜单 - 上架菜单】底部弹窗交互为全项目统一标准范本。

## 强制规则（所有新增、编辑类操作表单必须遵守）

1. **禁止内嵌平铺**：编辑/新增表单不得静态平铺嵌入页面正文流，禁止与页面其他内容上下拼接混排。
2. **触发方式**：点击操作按钮（如「上架菜单」「添加餐厅」「添加纪念日」）→ 从页面底部弹出弹窗承载表单。
3. **层级隔离**：弹窗弹出时，底层页面必须覆盖半透明遮罩（`mask`），置灰弱化，引导用户聚焦当前操作。
4. **关闭即消失**：保存成功或点击「取消」/ 遮罩后，弹窗关闭，表单完全消失，页面恢复原始浏览状态。
5. **允许的替代形式**：独立新页面（如 space-create / space-join）也符合规范；其余一律底部弹窗。

## 标准实现模板（WXML）

```xml
<view class="modal" wx:if="{{showXxxForm}}">
  <view class="mask" bindtap="onHideXxxForm"></view>
  <view class="sheet">
    <view class="sheet-handle"></view>
    <view class="form-title">标题</view>
    <!-- 表单字段（统一用 .field-label + .input / .picker-value） -->
    <view class="form-actions">
      <button class="btn-secondary form-btn" bindtap="onHideXxxForm">取消</button>
      <button class="btn-primary form-btn" bindtap="onSaveXxx">保存</button>
    </view>
  </view>
</view>
```

全局样式（`app.wxss`）：`.modal`（fixed 全屏，z-index 1000）、`.mask`（rgba 遮罩）、`.sheet`（底部圆角 + 上滑动画 + 最大高度 86vh 可滚动）、`.sheet-handle`（顶部小把手）。

## 验收检查项

- 页面浏览态：无任何表单区块（`class="form"` 内嵌计数 = 0）。
- 点击触发后：`showXxxForm` 由 false → true，弹窗出现且底层有遮罩。
- 保存/取消后：`showXxxForm` 由 true → false，弹窗与遮罩完全消失。
- 新增功能的代码评审必须对照本规范，禁止回归内嵌式表单。

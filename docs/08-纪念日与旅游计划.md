# 08 纪念日与旅游计划（第六阶段）

## 1. 纪念日

- 双人平等：新增、编辑；**仅主账号可删除**（删除进回收站，72 小时内可恢复）。
- 永久保存，不自动清理。
- 默认“每年重复”，下一次发生日自动按 Asia/Shanghai 计算；非闰年 2 月 29 日自动回退到 2 月 28 日。
- 列表显示倒计时/正计时（“还有 N 天”“已 N 天”），首页摘要显示最近一个纪念日。
- 日历联动：月视图按“每年重复”生成 ❤️ 纪念日事件（读时计算，不落库），点击日历事件可跳转到纪念日页。

## 2. 旅游计划（永久资料）

- 双人平等：新增、编辑；**仅主账号可删除**（进回收站，永久保留类型）。
- 字段：名称、国家/地区、城市、交通、酒店、备注、照片、经纬度、行程清单。
- 行程清单格式（每行）：`YYYY-MM-DD 标题 | 备注`，日期可省略。
- 不自动清理。

## 3. 临时行程（14 天）

- 可关联一条旅行资料（自动带名称），也可独立创建。
- 创建后 **14 天**自动进入回收站，**72 小时**后永久删除（由 `daily-maintenance` 每天 04:00 执行）。
- 下架后不再出现在列表与日历；主账号可删除。
- 日历联动：带时间生成 `✈️ 名称` 事件；无时间生成全天事件（日历显示“全天”）。恢复回收站记录后自动重建日历事件。

## 4. 数据库

- 新集合：`anniversaries`、`trips`、`trip_plans`（已创建，权限 ADMINONLY）。
- 建库/权限脚本：`node scripts/db-bootstrap.cjs`（已包含本阶段集合）、`node scripts/set-db-acl.cjs`。

## 5. 验证

- 单元测试：`tests/anniversary-travel.test.ts`（权限、跨空间、14 天/72 小时生命周期、日历联动）。
- 云端 E2E：`npm run test:e2e`（连接真实云环境，创建临时空间后自动清理）。

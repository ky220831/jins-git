## 需要开发者完成的两件事

### 1. 安装微信开发者工具

打开官方下载页（只认这个域名）：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

- 选择 **稳定版 Stable Build / Windows 64 位** 安装包；
- 双击安装，一路默认；
- 安装后打开，用**微信扫码登录**。

预期：进入工具主页，能看到“导入项目”等入口。

### 2. 开通云开发并创建环境

1. 在开发者工具中点击工具栏「云开发」；
2. 点击「开通」，按提示创建一个免费云环境（当前官方政策：未发布上线阶段免费，无需续费）；
3. 记录控制台顶部的**环境 ID**（形如 `cloud1-xxxx`）；
4. 如果只有一个环境，`apps/miniprogram/miniprogram/config/env.ts` 中的 `ENV_ID` 保持空字符串即可；有多个环境时填入该 ID。

预期：云开发控制台能打开，数据库、云函数、云存储三个入口可用。

## 常用命令（项目根目录执行）

```powershell
npm install            # 安装构建/测试工具（第一次执行一次）
npm run sync           # 同步共享类型到小程序
npm run typecheck      # TypeScript 类型检查
npm test               # 跨 Space 安全测试
npm run build          # 打包云函数到 cloudfunctions/*/dist/
tcb -v                 # 查看 CloudBase CLI 版本
```

## 常见错误

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `tcb` 不是内部或外部命令 | CloudBase CLI 未安装或未全局生效 | `npm i -g @cloudbase/cli`，重开终端 |
| 开发者工具提示找不到云环境 | 未开通云开发 / 环境未创建 | 按上文第 2 节开通 |
| 上传云函数失败 | 未先执行 `npm run build` | 项目根目录执行 `npm install` 后 `npm run build` |
| 调用云函数返回“服务器开小差了” | 云函数未部署 / 集合未创建 / 云函数代码报错 | 检查云函数是否已上传，集合名是否与文档一致，查看云函数日志 |

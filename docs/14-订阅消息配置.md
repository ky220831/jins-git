# 14 订阅消息提醒配置（1.1.0）

## 生效前提

1. 在 小程序后台（mp.weixin.qq.com）→ 功能 → 订阅消息 → 公共模板库，选用 4 个**一次性订阅**模板：
   - 纪念日提醒：搜索“纪念日 / 重要日子”
   - 今日菜单提醒：搜索“吃饭 / 用餐 / 就餐”
   - 餐厅行程提醒：搜索“行程 / 出行”
2. 回到「我的模板」页，复制每个模板的 **模板ID**（一长串字符）和**关键词（字段名）**。

## 字段匹配

代码发送的数据字段：
- 纪念日：`thing1`（类型）、`date2`（具体日期）、`date3`（纪念日期=原始纪念日）
- 菜单/行程：`thing1`（提醒事项）、`date2`（提醒日期）、`time3`（提醒时间，无时间填“全天”）

字段映射在 `reminderService.ts` 的 `sendDue` 中按 topic 区分。

## 提醒范围

- 纪念日：当天提醒
- 今日菜单：上架当天且填了时间的提醒
- 餐厅行程：行程当天提醒

一次性授权：用户每次点“开启提醒”获得 1 条发送额度，发完自动失效；同一用户可再次开启。
每日发送由 `daily-maintenance` 定时任务（每天 04:00）执行。

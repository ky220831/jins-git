# 14 订阅消息提醒配置（1.1.0）

## 生效前提

1. 在 小程序后台（mp.weixin.qq.com）→ 功能 → 订阅消息 → 公共模板库，选用 4 个**一次性订阅**模板：
   - 纪念日提醒：搜索“纪念日 / 重要日子”
   - 今日菜单提醒：搜索“吃饭 / 用餐 / 就餐”
   - 餐厅行程提醒：搜索“行程 / 出行”
2. 回到「我的模板」页，复制每个模板的 **模板ID**（一长串字符）和**关键词（字段名）**。

## 填入位置

文件：`apps/miniprogram/cloudfunctions/_shared/constants.ts` 的 `REMINDER_TEMPLATES`：

```ts
export const REMINDER_TEMPLATES = {
  anniversary: { templateId: '填入纪念日模板ID', page: 'pages/anniversary/index' },
  meal: { templateId: '填入菜单模板ID', page: 'pages/meal/index' },
  visit: { templateId: '填入行程模板ID', page: 'pages/restaurant/index' },
} as const;
```

模板未填时：客户端「开启提醒」按钮会提示“模板未配置”，其余功能不受影响。

## 字段匹配

代码发送的数据字段为 `thing1`（事项）、`date2`（日期）、`time3`（时间）。
所选模板的字段类型最好依次是「事项、日期、时间」；如果不同，把实际字段名发来，按需调整
`reminderService.ts` 中 `sendDue` 的 data 映射。

## 提醒范围

- 纪念日：当天提醒
- 今日菜单：上架当天且填了时间的提醒
- 餐厅行程：行程当天提醒

一次性授权：用户每次点“开启提醒”获得 1 条发送额度，发完自动失效；同一用户可再次开启。
每日发送由 `daily-maintenance` 定时任务（每天 04:00）执行。
